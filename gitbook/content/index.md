# Welcome to 9Remote

**Access your terminal, desktop, and files from anywhere in the world.**

## What is 9Remote?

9Remote is a powerful remote access tool that lets you control your computer from any device with a browser. No complex setup, no port forwarding, no VPN configuration needed.

### Key Features

- **[icon:monitor] Remote Terminal** - Full terminal access with multi-session support
- **[icon:mouse] Remote Desktop** - Control your desktop with mouse and keyboard
- **[icon:folder] File Explorer** - Browse, edit files, and manage Git repositories
- **[icon:lock] Secure by Default** - Encrypted connections via Cloudflare tunnel
- **[icon:zap] Zero Configuration** - Just one command to start
- **[icon:smartphone] Works Everywhere** - Browser, mobile, desktop - all supported

### Why Choose 9Remote?

**Simple Setup**
```bash
npm install -g 9remote
9remote
```

That's it! Scan the QR code and you're connected.

**No Network Hassle**
- No public IP needed
- No port forwarding
- No firewall configuration
- Cloudflare tunnel handles everything

**Fast & Reliable**
- Low latency (< 50ms)
- Real-time synchronization
- Optimized for mobile networks
